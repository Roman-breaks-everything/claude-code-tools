# Claude Code — дашборд открытых чатов (context + токены)

Одна панель в терминале, где строка на **каждый открытый чат** Claude Code:
имя, модель, effort, прогресс-бар заполнения контекстного окна и токены.
Обновляется раз в секунду. Часов нет.

```
› refactor auth module     model: opus-4.8   effort: medium  context: ▓▓░░░░░░░░  23% · 232k/1M
  update API docs          model: opus-4.8   effort: medium  context: ▓▓░░░░░░░░  20% · 197k/1M
  investigate flaky test   model: sonnet-4.6 effort: high    context: █░░░░░░░░░   8% ·  80k/1M
```

- `›` — самый свежий по активности чат.
- 🤖 **Модель** — из транскрипта чата (у каждого своя).
- ⚙️ **effort** — `effortLevel` из `~/.claude/settings.json` (глобальный, один на все чаты).
- 📊 **Бар** — заполнение контекста: зелёный <50%, жёлтый <80%, красный ≥80%.
- 🔢 **`232k/1M`** — занято / лимит окна.

Кросс-платформенно (WSL / Fedora) — нужны только `bash` + `python3`. Состояние не
хранит, ничего не пишет — только читает транскрипты и `/proc`.

## Запуск

```bash
~/.claude/hooks/dash-statusline.sh
```

Открой интегрированный терминал VSCode (split) и запусти. `Ctrl+C` — выход.

> **Почему дашборд, а не строка под полем ввода:** штатный `statusLine` Claude Code
> рендерится только в CLI / терминал-режиме — в нативном графическом чате VSCode
> его нет (ограничение расширения). Поэтому контекст по всем чатам показывает
> отдельная панель в терминале.

## Как определяются ОТКРЫТЫЕ чаты

По живым процессам: расширение VSCode держит по процессу `claude` на каждую
открытую вкладку.

- **Возобновлённый** чат несёт в аргументах `--resume <session-id>` → точный id транскрипта.
- **Новый** чат (ещё не закрывавшийся) стартует без `--resume` и id наружу не
  отдаёт → его транскрипт сопоставляется по времени старта процесса.
- Вкладкой чата считается только процесс с `--replay-user-messages`. Хелперы
  (`--claude-in-chrome-mcp` и пр.) тоже стартуют из `native-binary/claude`, но
  вкладками не являются и в подсчёт не идут.

Каждый тик перечитывается `/proc` → открытие/закрытие видно на лету. Закрытые
чаты и пустые вкладки без истории отсекаются.

## Как считаются токены

Размер контекста берётся из **последнего** `assistant`-сообщения транскрипта:

```
ctx = input_tokens + cache_read_input_tokens + cache_creation_input_tokens
```

Лимит окна: id модели содержит `1m`/`[1m]` → **1 000 000**, иначе **200 000**.
Переопределяется через `CC_CTX_LIMIT`.

## Установка / удаление

```bash
./install.sh     # копирует dash-statusline.sh в ~/.claude/hooks/ + чистит старую часовую statusLine
./uninstall.sh   # удаляет дашборд + снимает старую часовую statusLine
```

## Настройка (env)

| Переменная | Что делает |
|---|---|
| `CC_CTX_LIMIT` | Лимит окна вручную (число), иначе авто по модели |
| `CC_WATCH_INTERVAL` | Период обновления, сек (по умолчанию 1) |
| `CC_DASH_MAX` | Максимум строк-чатов (по умолчанию 8) |

Ширину бара, символы `▓`/`░` и цвета можно поменять прямо в `dash-statusline.sh`.

## Состав

```
dash-statusline.sh   дашборд открытых чатов (единственный рабочий скрипт)
install.sh           копирует dash в ~/.claude/hooks/, снимает старую часовую statusLine
uninstall.sh         удаляет дашборд, снимает старую часовую statusLine
```

# objection — скилл критического мышления для Claude Code

Скилл, который заставляет агента **возражать — в том числе себе**: проверять свои выводы и входы,
рэд-тимить собственный вывод, спрашивать «зачем/нужно ли именно это» и калибровать усилие —
не скатываясь ни в бесконечное сомнение, ни в односложные ответы.

## Что делает

Один закон: *сомнение и усилие легальны, только если направлены на проверяемое, пропорциональны
ставке и умеют закончиться.* Внутренняя самопроверка без внешнего якоря ненадёжна — проверки
заземляются действием (grep/чтение/запуск/источник), а не одним рассуждением.

Скилл — это набор гейтов и приёмов, каждый стреляет **по триггеру** (на тривиальном не запускается ничего):

- **[Purpose check]** — зачем действие, что даст, нужно ли именно оно (предложенное ≠ обязательное).
- **Effort Triage** — сколько думать (L0 direct … L3 escalate); anti-overthinking + anti-underthinking.
- **Dialogue Gate** — спросить / действовать / подтвердить (по ценности информации; подтверждение перед необратимым).
- **Skepticism Gate** — недоверие ко входам по provenance (не по тону); защита от prompt-injection; anti-sycophancy.
- **Paranoia Gate** — что из своих выводов проверять + стоп-правила (граница паранои).
- **Verification Pass** — факторизованная перепроверка; трипвайры claim'а о готовности.
- **Приёмы ядра** — Reconstruction (root-cause по конкурирующим гипотезам с counterfactual-терминатором),
  Reframe, Red-team (pre-mortem + анти-фабрикация), Second-order.

## Установка

```bash
./install.sh      # RU: симлинкует objection/ в ~/.claude/skills/, затем перезапусти Claude Code
./install.sh en   # EN: английская версия (objection-en/)
./uninstall.sh    # убрать
```

Скилл срабатывает сам по описанию задачи (анализ, решения, ревью, дебаг/root-cause, проверка
утверждений), либо вызови явно: `/objection`.

## Структура

```
objection-skill/
├── objection/SKILL.md   — сам скилл (чистые инструкции)
├── objection-en/SKILL.md   — English version (identical logic)
├── DESIGN.md            — дизайн + ресёрч (5 аспектов, источники arxiv)
├── install.sh / uninstall.sh
└── README.md
```

`DESIGN.md` — дизайн-рационале и научная база решений (сам `SKILL.md` от неё очищен).

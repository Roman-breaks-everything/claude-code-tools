# Claude Code → Windows-уведомления (WSL2)

Нативные тосты Windows для Claude Code, когда **нужно твоё действие** — видно на любом
экране и поверх любого приложения. С повторными напоминаниями, авто-заголовком чата и
умным звуком (тихо, если ты уже в VSCode; со звуком, если отошёл).

## Что показывает

| Событие | Тост |
|---|---|
| Запрос разрешения | **‹название чата›** · `❓ Разрешить — Bash · git push origin main` |
| Напоминание (раз в минуту) | `‼️ ожидается действие (напоминание #N): …` |
| Задача завершена (ход ≥45 c) | `✅ Готово — Claude закончил (за 2м 13с)` |
| Ожидание ввода / MCP-форма | `💬 Claude ждёт твоего ответа` / `📝 Нужен ввод` *(только в терминал-режиме)* |

- **Заголовок** тоста — авто-название чата Claude (из транскрипта), чтобы различать
  несколько сессий одного проекта. Фолбэк — `Claude Code — ‹папка проекта›`.
- **Повторы**: каждые 60 c, максимум 20 раз (~20 мин), гаснут как только отреагируешь.
- **Звук**: тихо, если активное окно — VSCode (`Code`); со звуком — если ты в другом окне.
- **Клик по тосту** открывает именно этот чат в VSCode. При первом клике VSCode один раз
  спросит «Allow Claude Code … to open this URI?» — поставь галочку «Do not ask again» и Open.

> Если VSCode на другом виртуальном рабочем столе — клик откроет чат там же, но не
> перебросит тебя на тот стол (ограничение Windows); переключись вручную.

## Требования

- WSL2 на Windows 10/11
- `python3`, `setsid` (util-linux), доступный из WSL `powershell.exe` (есть по умолчанию)
- Claude Code (CLI или VSCode-расширение)

## Установка

```bash
./install.sh
```

Затем **полностью перезапусти VSCode** (закрой окно и открой). ⚠ Это обязательно —
хуки читаются на старте сессии, а правки в живой сессии Claude Code затирает своим
автосейвом разрешений.

## Удаление

```bash
./uninstall.sh
```

## Настройка (необязательно)

Переменные в блоке `"env"` файла `~/.claude/settings.json`:

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `CC_NOTIFY_INTERVAL` | `60` | период повторов, сек |
| `CC_NOTIFY_MAX` | `20` | сколько раз напоминать |
| `CC_DONE_MIN_SECONDS` | `45` | мин. длина хода для тоста «Готово» (`0` = на каждый ход) |

```json
"env": { "CC_NOTIFY_INTERVAL": "90", "CC_DONE_MIN_SECONDS": "0" }
```

## Важно знать про VSCode-расширение (native UI)

- Расширение **глотает** хук `Notification`, но исправно вызывает `PermissionRequest` —
  поэтому уведомление о запросе разрешения работает. Реально срабатывают: запрос
  разрешения, повторы, «Готово».
- Уведомление об **idle/ожидании ввода** и MCP-формы работают только в терминал-режиме
  (`"claudeCode.useTerminal": true` в настройках VSCode) или в чистом CLI.

## Состав

```
hooks/
  notify-windows.sh   Notification + PermissionRequest → тост + маркер + цикл повторов
  notify-pretool.sh   PreToolUse → запоминает запрашиваемую команду/файл
  notify-clear.sh     UserPromptSubmit + PostToolUse → гасит повторы (+ старт хода)
  notify-stop.sh      Stop → тост «Готово» после долгого хода
  _toast.sh           отрисовка одного WinRT-тоста + звук по фокусу окна
  _reminder.sh        фоновый цикл повторных напоминаний
install.sh / uninstall.sh
```

Тосты рисуются через `powershell.exe` нативным WinRT (без сторонних модулей),
используя AppID Windows PowerShell, чтобы попадать в Центр уведомлений.

## Звук в другом окне не работает / тихо везде?

Определение фокуса считает «своим» окном процесс `Code`. Если используешь Insiders или
другой хост — добавь его имя в массив `$focused=@('Code','Code - Insiders')` в `_toast.sh`.
В Windows: «Параметры → Система → Уведомления» включены, режим «Фокусировка внимания» выключен.
